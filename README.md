# Eclipse releases

Downloadable APKs of the Eclipse Android app. The source code lives in a private repo.

## Install

1. On the phone, open the [latest release](https://github.com/Gilmorecollins/Eclipse-releases/releases/latest) and download the `Eclipse-x.y.apk` file.
2. Open the download. If Android asks, allow your browser to install unknown apps.
3. Tap **Install**.

## Updates

When a newer version is published here, Eclipse shows an "Eclipse x.y is available" bar on launch. Tap **UPDATE** to download it, then install it over the existing app. Your sign-ins and settings are kept.
